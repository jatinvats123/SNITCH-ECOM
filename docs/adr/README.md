# Architecture Decision Records

Each ADR captures one significant, hard-to-reverse decision: the context, the
decision, and its consequences. They are immutable — to change a decision, add a new
ADR that supersedes an old one rather than editing history.

Format: a lightweight [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions)–style record.
